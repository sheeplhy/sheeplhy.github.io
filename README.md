## 发布新文章

在 `_posts` 目录创建 Markdown 文件，文件名格式：

```text
YYYY-MM-DD-english-title.md
```

文章开头示例：

```yaml
---
layout: post
title: "文章标题"
description: 一句话摘要
date: 2026-10-08 12:00:00 +0800
categories: 图像处理
---
```

提交到 `main` 分支后，GitHub Pages 会自动重新发布。
