## 关于我

软件工程专业，关注移动应用、桌面软件与智能终端方向。喜欢从实际场景出发理解问题，并通过设计、开发、测试和复盘，把想法逐步转化为可以验证的软件功能。

## 技术方向

- **App 开发：** iOS / Android 应用、Windows 桌面程序、界面交互与系统能力接入
- **计算机视觉：** Python、OpenCV、图像处理、数据预处理与视觉算法实践
- **消费电子：** 智能眼镜、移动终端、Camera / ISP 与整机质量验证
- **嵌入式软件：** ESP32-S3、传感器融合、软硬件联调与端侧功能原型

## AI 能力

持续学习 AI 辅助开发、多模态模型与视觉算法的实际应用，关注如何利用 AI 提升需求分析、代码实现、资料整理和测试验证的效率。同时重视结果校验、数据安全和能力边界，不把模型输出直接当作最终答案。

## 产品思维

重视用户需求、使用场景与技术实现之间的联系。习惯先拆解问题和核心目标，再完成方案设计、功能实现、可用性验证与迭代优化，并通过文档记录关键选择和问题闭环。
